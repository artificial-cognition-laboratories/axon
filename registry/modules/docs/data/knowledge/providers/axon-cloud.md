# Axon Cloud

The zero-config option. If you're logged in, Axon Cloud is already active — press `*` to
open the model palette, pick a model, and start a session. Nothing to install, no key to
paste.

::TerminalImage{src="/tui/axontuimodelpaletteopenopenroutertabactive.webp" alt="TUI model palette showing models grouped by provider across tabs"}
::

## Free credits

Every new account starts with free credits. That's enough to boot an agent, watch it call
a tool, reason over the result, and answer — the whole loop — before you spend anything.
No card required to reach it.

## Topping up

When the free credits run low, add more from [billing](/dashboard/billing). Credits power
inference on the managed `Axon()` provider, plus Axon's own services — deployments,
voice, and speech-to-text. Nothing else draws on your balance.

Prefer to run on your own inference? [Codex](/docs/v2/providers/codex),
[OpenRouter](/docs/v2/providers/openrouter), and [Ollama](/docs/v2/providers/ollama) all
bill through your own accounts — Axon takes no cut, and you can leave the Cloud balance
untouched.

Connected? [Your First Agent](/docs/v2/getting-started/first-agent) is next.
