# axon settings

Open your active profile's settings file in `$EDITOR`.

```bash
axon settings
```

This is the same `settings.json` that `axon watch`/`axon unwatch` write to
— useful if you want to see the full list of watched directories at a
glance, or edit it by hand. There's no separate config format to learn: the
file you get is the file the CLI itself reads and writes.
